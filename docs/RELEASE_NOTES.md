## Pulse v1.0 🎉

The first production release of **Pulse**, a real-time chat platform simulation with 56 AI-driven users.

### Downloads

| File | What it is |
|---|---|
| `PulseChat.apk` | Android app (Capacitor). Enable *Install unknown apps* to sideload. |
| `PulseChat-web.zip` | The full web app as a static site. Unzip and serve with any static server. |
| `PulseLite-windows.zip` | Pulse Lite, the Godot 4 companion client for Windows |
| `PulseLite-linux.zip` | Pulse Lite for Linux |
| `PulseLite-web.zip` | Pulse Lite web build |

Prefer the browser? **Play online:** https://jaineil32624.github.io/chat-platform/

### Highlights

- Servers, channels, DMs, group DMs, threads, replies, reactions, pins and saved messages
- Typing indicators, presence, read receipts, notifications, all live
- Voice notes, GIFs, stickers, image and file uploads, meme generator
- Polls, trivia, shared whiteboard, voice/video call UI with screen share
- XP, levels, streaks, achievements, badges and reputation
- Role and permission system, admin dashboard, moderation tools
- Nova AI assistant (offline, or Claude with your own key)
- Dark and light themes, accent colors, glassmorphism, responsive layouts
